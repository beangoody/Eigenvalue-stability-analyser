# Eigenvalue stability analyser

Small project to analyse stability via eigenvalue computations.

## Quick start

1. Create a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate  # or .venv\\Scripts\\activate on Windows
```

2. Install dependencies (if any):

```bash
pip install -r requirements.txt
```

3. Run the analyser (example):

```bash
python -m eigen_stability.main
```
